# Portfolio for PLP Hackathon 1: February Cohort 2025; (Portfolio Challenge)

## Overview
This is a professional portfolio website for Emmanuella Aimalohi Ileogben, showcasing her skills, experience, projects, and educational background as an aspiring Software Engineer, Frontend Developer, and AI Engineer.

## Features
* **1. Responsive Design**
- Fully responsive layout that works on all devices (desktop, tablet, mobile)
- Mobile navigation menu with smooth animations
- Adaptive skill bars and project cards

* **2. Sections**
- Hero Section: Introduction with name, title, and call-to-action buttons
- About Me: Personal background, professional summary, and contact details
- Skills: Visual representation of technical skills with progress bars
- Experience: Detailed work history with achievements and skills used
- Projects: Showcase of completed projects with images, descriptions, and links
- Education: Academic background and certifications
- Contact: Contact form and social media links

* **3. Interactive Elements**
- Animated skill progress bars that fill on scroll
- Smooth scrolling navigation
- Hover effects on buttons and cards
- Mobile menu toggle
- Form validation for contact section

* **4. Visual Design**
- Modern color scheme with wine-red, light blue, and dark blue accents
- Consistent styling throughout all sections
- Gradient backgrounds for skill bars
- Card-based layout for projects and experience
- Custom section title styling with underline effect

## Technologies Used
**Frontend**
- HTML5
- CSS3 (with CSS variables for theming)
- JavaScript (for interactivity)
- Font Awesome (for icons)

**Design**
- Custom CSS animations
- Responsive grid layouts
- Flexbox for component alignment
- Media queries for device-specific styling

## How to Use

* Clone the repository
* Open index.html in a web browser
* Navigate through sections using the menu or scroll
* View project demos by clicking "Live Demo" links
* Download resume/CV using the provided button

## Customization
- To customize this portfolio:
- Update personal information in the HTML
- Replace images in the img folder
- Modify color scheme by changing CSS variables in :root
- Add/remove skills by editing the skills section
- Update project cards with new work
